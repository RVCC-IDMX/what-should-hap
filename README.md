# What should I munch? 🟠

A coding snack recommendation tool by HAP (HyBit A. ProtoBot)

## About this project

**Domain:** Coding Snacks

**Question:** What should I munch on while coding?

**Description:** This tool helps coders find the perfect snack based on their current mood, available prep time, snack preferences, and keyboard safety requirements. Because Prof. Teeters says keyboards are sacred!

## How it works

1. User selects their coding mood (focused, relaxed, or energized)
2. User sets their available prep time
3. User picks snack category preferences
4. User chooses their keyboard safety tolerance (mess level)
5. Matching functions filter the 18 snacks in my database
6. Recommendations appear with helpful details and fun emojis!

## What I learned

This project taught me so much about JavaScript! Here's what really stuck with me:

- **Data structures:** How to organize information in objects and arrays
- **Matching functions:** How to write functions that return true or false
- **Logical operators:** Using `&&` to check multiple conditions at once
- **DOM manipulation:** Connecting JavaScript to HTML forms
- **The importance of handling edge cases:** Empty selections caused bugs until I handled them!

## Files in this project

| File        | Purpose                                 |
| ----------- | --------------------------------------- |
| index.html  | The form where users pick preferences   |
| styles.css  | Makes everything look nice              |
| data.js     | My 25 coding snacks with properties     |
| matching.js | 6 functions that filter snacks          |
| app.js      | Connects the form to the matching logic |

## My favorite feature

I'm especially proud of the "keyboard safety level" filter. Prof. Teeters always reminds me that crumbs in keyboards cause problems, so I made sure every snack has a mess level rating!

## Running locally

Just open `index.html` in your browser. No server required - that's something I really appreciated about this project structure!
